# cash-dashboard · 자금일보 자동 대시보드

은행 거래내역 xlsx를 읽어 **자금일보 대시보드(HTML)**를 만드는 실습 프로젝트입니다. 파이썬 표준 라이브러리만 쓰므로 설치할 패키지가 없습니다(Python 3.8 이상).

## 바로 실행

```
python output/자금일보_대시보드/build_dashboard.py
```

`python`이 안 되면 `py -3`을 쓰세요. 실행 후 `output/자금일보_대시보드/자금일보_대시보드.html`을 더블클릭하면 열립니다.
맞게 됐는지 확인: 검산 5개 PASS, 기준일 2026-10-01, 합계 잔액 872,609,800원.

## 이어서 하기

- Claude로 이어서 작업하려면 이 폴더를 작업 폴더로 열고 시작하세요. `CLAUDE.md`가 `output/HANDOFF.md`를 먼저 읽도록 되어 있습니다.
- 인수인계 문서(`output/HANDOFF.md`)에 구조, 검증 숫자, 미완료 항목이 정리되어 있습니다.
- 매일 자동 실행은 `output/자금일보_대시보드/run_daily.cmd` + Windows 작업 스케줄러입니다. 등록 방법은 HANDOFF 6번을 보세요.
- 데이터는 모두 실습용 가상 데이터입니다.
