# HANDOFF — 자금일보 대시보드 (2026-10-29 작성)

새 Claude 세션이 이 파일만 읽고 바로 이어서 일할 수 있게 쓴 인수인계 문서.
작업 폴더: `4_자금일보/` (이 파일은 `4_자금일보/output/HANDOFF.md`). 폴더 규칙은 `4_자금일보/CLAUDE.md`가 우선.

## 1. 한 줄 요약

(주)다온생활 은행 거래내역 xlsx를 읽어 **자금일보 대시보드 HTML**을 만드는 파이썬 스크립트를 만들었고, 평일 08:30 자동 빌드 예약(Windows 작업 스케줄러)까지 붙였다. 데모 데이터(9/1~10/1)로 검산 5/5 PASS 확인. **LLM은 매일 도는 부분에 안 들어간다.**

## 5. 동작 규칙 (코드에 들어간 결정사항)

- **파일 탐색**: 루트의 `*거래내역*.xlsx`(이름이 `국민`/`신한`으로 시작) + `추가자료*/거래내역_*.xlsx`(시트 2개, 시트명에 국민/신한 포함). 월 파일과 일 파일에 같은 거래가 겹치면 (계좌·일자·시각·입금·출금·잔액) 키로 중복 제거.
- **은행별 열 이름이 다르다**: 국민 `입금/출금/구분/의뢰인·수취인`, 신한 `맡기신금액=입금 / 찾으신금액=출금 / 적요 / 기재내용`. 열 이름으로 매핑한다(순서 가정 금지 — 신한은 출금 열이 입금 열보다 앞).
- **계좌간이체 판정**: 거래처·내용에 `(주)다온생활`이 있고, 같은 날·같은 금액·반대 방향·다른 계좌인 쌍만 이체. 시간이 가장 가까운 쌍을 매칭. 회사명 없는 거래는 금액이 같아도 이체 아님(예: 10/1 미래보험 사내몰 입금 3,100,000). 짝 없는 회사명 거래가 있으면 검산 FAIL.
- **검산 5개**: ①행별 잔액 연속성 ②일별 전일잔액+입금−출금=금일잔액 ③이체 짝 맞춤 ④이체 입금합=출금합 ⑤월말 잔액=`은행잔액대사_*.xlsx`(파일이 있을 때).
- **일별 축**: 거래가 있었던 날만(영업일). 거래 없는 계좌는 전일 잔액 이월. 월누계는 월 1일부터.
- **차트**: 최근 22거래일 롤링 창, 선택 날짜가 창 밖이면 창 이동. 그래프 단위 백만원.
- **경고 배너**: 브라우저로 연 날짜 기준 직전 영업일 거래가 없으면 "최신 거래내역 확인 필요" 표시(공휴일은 못 거름). 데모 데이터가 10/1까지라 지금은 항상 뜸.
- xlsx는 `zipfile + xml.etree`로 직접 읽음(openpyxl 미설치 환경이라서).

## 6. 예약 실행 (이 PC 기준 — 새 PC에서는 다시 등록해야 함)

- 작업 이름 `DaonCashDashboard`, 평일 08:30, `cmd.exe /c ...\run_daily.cmd`, 사용자 로그온 시 실행, 놓치면 켜질 때 실행(`StartWhenAvailable`), 제한시간 10분. 스케줄러로 직접 1회 돌려 exit 0 확인함.
- 새 PC 등록:
  1. `where python`으로 경로 확인 → `run_daily.cmd`의 파이썬 경로 줄 수정.
  2. 아래 등록 (경로는 실제 위치로):

```powershell
$cmd = "<4_자금일보 절대경로>\output\자금일보_대시보드\run_daily.cmd"
$action   = New-ScheduledTaskAction -Execute 'cmd.exe' -Argument "/c `"$cmd`""
$trigger  = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -At 8:30AM
$settings = New-ScheduledTaskSettingsSet -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit (New-TimeSpan -Minutes 10)
Register-ScheduledTask -TaskName 'DaonCashDashboard' -Action $action -Trigger $trigger -Settings $settings
```

  3. 해제: `Unregister-ScheduledTask -TaskName DaonCashDashboard -Confirm:$false`
- 한계: PC 꺼져 있으면 그 시각엔 안 돎. FAIL 알림 없음(대시보드 상단 검산 바와 build.log로만 확인).

## 7. 아직 안 한 것 / 열린 이슈

1. **검증 못 한 UI**: 차트 마우스 hover 툴팁·클릭 이동은 눈으로 직접 안 눌러봄(브라우저 패널이 좁고 스크린샷이 가끔 타임아웃). 다크 모드도 미확인. 날짜 전환 로직은 JS로 9/23 케이스를 확인함.
2. **실제 새 날짜 파일(10/2 등)로는 아직 안 돌려봄.** `추가자료*` 폴더에 `거래내역_2026-10-02.xlsx`를 넣고 재빌드하는 테스트가 필요.
3. **알림 없음**: FAIL이나 파일 누락을 메일·카톡으로 알려주는 기능 없음.
4. **계정과목 분류·일반전표 자동화 미구현**: 이쪽은 규칙만으로 부족해 LLM이 필요할 수 있음. 계정 코드는 `일반전표/계정과목표.xlsx`, `거래처목록.xlsx`만 근거(CLAUDE.md). 위하고 실제 업로드 금지.
5. **Build vs Buy**: 기성 SaaS(Clobe, 웹케시 대시보드, 볼타)가 존재함을 검색으로 확인(마케팅 글 위주, 요금·지원 은행 미확인). 은행 API 직접 연동이 목표면 SaaS가 낫고, 파일 내려받아 넣는 방식이면 현재 구조로 충분 — 사용자는 후자(파일 드롭+예약)를 선택함. SaaS 비교는 요청이 오면 진행.
6. 공휴일 캘린더 미반영(경고 배너 오탐 가능).
